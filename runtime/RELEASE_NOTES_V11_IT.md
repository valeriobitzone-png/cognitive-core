# WorldCore 1.1 — WHAT IF universale, senza dipendenze progettuali

**Aggiunte:** confronto Multiverse, ricerca a ritroso, stress test degli assunti, confronto tra previsioni ed esiti, osservazioni di strumenti tramite Claude Code e OpenCode V1/V2, interfacce MCP, plugin OpenClaw esteso.

**Non aggiunte:** alcun framework aziendale, schema organizzativo, agente proprietario o backend dedicato a un prodotto. Il concetto WHAT IF viene utilizzato solo come metodo di simulazione e verifica, integrabile con qualunque LLM tramite interfacce standard.

**Validazione:** 248 test Python e 10 Node.js eseguiti e superati, 4 benchmark sintetici di coerenza, wheel installata in isolamento. L'esecuzione del runner a processi isolati non è stata ricertificata fino alla fine e gli host reali non sono stati disponibili.

Per gli schemi dei tool, le istruzioni di integrazione, gli esempi e i limiti vedere `README.md`, `docs/WHATIF_V11_IT.md`, `docs/CLAUDE_OPENCODE_V11_IT.md`, `docs/VALIDATION_V11_IT.md`.
